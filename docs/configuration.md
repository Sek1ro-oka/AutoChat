# 手动修改配置与管理服务

所有命令先在 PowerShell 切换到项目目录：

```powershell
cd E:\AutoChat
```

## 人设／预设

默认人设在 `src/persona.js`。编辑反引号之间的中文提示词，保留 `export const DEFAULT_PERSONA =` 和末尾的反引号、分号；若文字中包含反引号或 `${`，需要按 JavaScript 语法转义。

另一种方式是编辑 `.env` 的 `SYSTEM_PROMPT`，填写自己完整的人设；它会覆盖默认预设。例如：

```dotenv
SYSTEM_PROMPT="你是一位熟悉网络梗的傲娇女生。说话简短、嘴毒，闲聊时偶尔只回梗和反问；对方要求认真回答时正面作答。"
```

保留 `SYSTEM_PROMPT=` 空值即可继续使用 `src/persona.js` 的默认预设。修改后重启服务；旧聊天上下文仍保留，想完全从新人设开始可以在相应私聊／群 @ 中发送 `/清空`。

## 私聊白名单与群

编辑本机 `.env`，不要改 `.env.example`：

- `PRIVATE_USER_QQS`：多个 QQ 号用英文逗号隔开。添加时在现有列表后追加，删除时移除对应号码。此字段有值时优先于旧 `PRIVATE_USER_QQ`。
- `GROUP_QQS`：多个响应群用英文逗号隔开，有值时优先于兼容字段 `GROUP_QQ`。新增群在现有列表后追加。机器人需要已经在对应群；白名单设置不会自动加好友或加群。不同群、不同成员上下文独立，各群分别每 72 小时清理；所有群和私聊共用每日预算。
- `GROUP_QQ`：兼容单群配置，`GROUP_QQS` 为空时使用。
- `ADMIN_QQ`：管理员 QQ，默认取私聊列表的第一个号码，建议明确填写。普通白名单用户不自动获得管理权限。

添加一人不需要修改旧的单用户字段。修改名单和群号后运行 `npm run bot:restart`。更改响应群只影响机器人回复，不解散 QQ 群，也不自动退群。

管理员 `/群关闭`、`/群开启` 控制全部白名单群；`/状态` 列出各群的下一次清理时间。

## 其他常用配置

### 多模型配置与私聊切换

旧字段 `MODEL_NAME`、`MODEL_BASE_URL`、`DEEPSEEK_API_KEY` 和原计价字段组成 `default` 配置，现有 `.env` 可继续使用。额外模型在 `MODEL_PROFILES` 列出标识，每个标识使用对应的大写前缀。例如 `MODEL_PROFILES=alt,backup` 对应 `MODEL_ALT_*` 和 `MODEL_BACKUP_*`，最多10个额外配置；标识只能使用小写字母、数字和下划线。

```dotenv
MODEL_PROFILES=alt
MODEL_ALT_NAME=填写服务商提供的模型ID
MODEL_ALT_BASE_URL=https://服务商地址/v1
MODEL_ALT_API_KEY=只在本机填写真实密钥
MODEL_ALT_PRICE_INPUT_CNY_PER_MILLION=填写人民币每百万输入token价格
MODEL_ALT_PRICE_OUTPUT_CNY_PER_MILLION=填写人民币每百万输出token价格
MODEL_ALT_PRICE_VERIFIED_DATE=填写YYYY-MM-DD
MODEL_ALT_MAX_OUTPUT_TOKENS=1024
MODEL_ALT_CONTEXT_INPUT_TOKENS=16000
MODEL_ALT_SUPPORTS_VISION=false
MODEL_ALT_SUPPORTS_SEARCH=false
MODEL_ALT_SEND_THINKING=false
```

以上是字段说明，示例中文占位值必须换成有效配置。接口需兼容 `/chat/completions`，`BASE_URL` 填接口根地址（通常带 `/v1`），不填写完整 `/chat/completions` 地址。仅支持无凭据、无查询参数的HTTPS地址；不同服务商API Key分别保存，不能在私聊命令里填写密钥、URL或任意模型名。额外配置需要独立核验人民币计价，原币价格需自行换算并保守填写；不要沿用DeepSeek价格猜测其他模型费用。字段不完整时配置校验失败，不会停掉原有服务。

改好 `.env` 后双击 `restart.cmd`，由 `ADMIN_QQ` 私聊：

- `/模型列表` 或 `/模型`：查看配置标识、模型名称、当前选择和声明的功能。
- `/切换模型 alt`：选择对应配置；`/切换模型 default` 回到原配置。
- `/状态`：查看当前模型与共同预算；`/清空` 只清空当前配置中的当前会话。

选择对所有私聊和群聊生效，在SQLite中只保存配置标识，不保存API Key。命令不产生模型费用、仅限管理员私聊，群管理员不能通过群命令切换全局模型；模型回复暂停期间仍能切换。不同配置的上下文独立，切换时不把原配置历史转发给新服务商，切回原配置继续其历史；所有配置共用每日金额预算和搜索次数。群会话仍按原72小时规则清理全部配置。删除已选择的配置后重启，会回到 `default`；建议一个标识固定对应一个模型与服务商，更换服务商时使用新标识。

切换成功表示本地配置已选中，不代表该服务商接口已经连通。`npm run check:model` 会使用当前选择发送一次真实请求并记入共同账本；未知费用继续保留预留额度，不自动换模型重试。其他服务商密钥需要你在本机填写，未填入的配置不会出现在列表中。

图片与搜索需要分别声明支持。额外模型默认 `SUPPORTS_VISION=false`、`SUPPORTS_SEARCH=false`，不支持时发送图片／搜索会提示切换，不调用收费接口；自动搜索遇到不支持的模型会走普通文本对话。仅当该模型兼容当前图片输入格式时开启图片，并必须填写 `MODEL_ALT_IMAGE_INPUT_RESERVE_TOKENS`（每张图片保守预留的输入token数）。DeepSeek默认配置每图额外预留2048；其他模型必须依据服务商的图片计费规则设置。搜索还要求同一服务商支持当前 `/anthropic/v1/messages` 的 `web_search_20250305` 结构与来源结果。普通额外配置默认不发送DeepSeek专用 `thinking` 字段，只有兼容且需要该参数时设置 `SEND_THINKING=true`。声明支持不会自动适配不兼容接口。

### 群内自动防刷屏

群内解除禁言：发送 `@机器人 解除禁言 @成员`，或按简写发送 `@机器人 禁言 @成员`（不带分钟数）。两种形式都支持命令前加 `/`，实际向 QQ 发送 `duration=0`。只有本群管理员或群主可使用，机器人必须有相应权限；机器人是群主时可解除管理员的禁言，机器人是管理员时只操作普通成员。显式“解除禁言”后不能再附加分钟数；“禁言”后带1～43200分钟仍执行禁言，填写0会提示用法。解除禁言不关闭防刷屏规则，目标继续刷屏时仍可能再次被禁言。

群内手动禁言：设置 `GROUP_ADMIN_COMMANDS_ENABLED=true` 并重启后，白名单群的管理员或群主可以发送 `@机器人 禁言 @成员 5`（或 `5分钟`），机器人是管理员时只禁言本群普通成员，是群主时也可禁言管理员；群主和机器人自身不能被禁言，时长1～43200整数分钟。也支持 `@机器人 /禁言 成员QQ号 5`。必须通过 QQ 真正选择并@机器人；关键词触发不能代替@。附图、附表情、@全体成员或同时@多个目标的命令会提示用法。请在QQ中实际选择并@目标成员，程序按消息中的QQ号识别，不根据昵称匹配；也兼容直接填写数字QQ号。

该权限独立于 `PRIVATE_USER_QQ` 和 `GROUP_MANAGEMENT_ENABLED`，群管理员不需要加入私聊白名单。每次实时查询发起者、机器人、目标的成员信息并核验账号和群号，不信任消息自带的角色字段。普通成员、私聊管理员身份、模型提示词均不能替代本群管理权限；无权限不会执行。命令不调用模型、不写入AI上下文，沿用消息去重和限流；机器人需要有本群管理权限，失败或超时不自动重试。AI回复暂停不影响明确的群管理命令。成功后在群内告知实际执行结果。

设置 `.env` 的 `GROUP_ANTI_SPAM_ENABLED=true` 后重启。默认 `GROUP_ANTI_SPAM_COUNT=5`、`GROUP_ANTI_SPAM_WINDOW_SECONDS=10`、`GROUP_ANTI_SPAM_MUTE_MINUTES=5`：同一成员在10秒内连续发送5条消息，禁言5分钟。其他成员或机器人发言打断连续计数；不同群分别计数，文字、图片和表情都计入。

禁言成功后会 @该成员并发送 `GROUP_ANTI_SPAM_REPLY="你话太多了！"`；可修改为自己的吐槽（最多200字），留空关闭提示。权限不足或操作失败／结果未知时不发成功吐槽，提示发送失败也不重复禁言或重发。提示是固定文本，不调用大模型。

此功能独立于私聊手动群管理开关、AI回复开关、@与关键词规则，在全部 `GROUP_QQS` 白名单群生效，防刷屏模块不调用模型，不额外保存消息内容，只保存事件去重编号和冷却时间；符合正常对话触发规则的消息仍按正常对话处理。执行前实时核验机器人与目标身份：机器人是管理员时只禁言普通成员，是群主时也可禁言刷屏的管理员；无权限则不执行，群主和机器人自身始终豁免。操作失败或超时不自动重试，同一目标至少冷却一个禁言周期（最少60秒），冷却记录重启后保留，连续消息计数重启后清零。关闭自动防刷屏不会解除已经执行的禁言，可由群管理员或现有 `/解除禁言` 命令解除。

支持直接发送 Unicode emoji（如 😂、🥰、👩🏽‍💻）和 QQ 原生表情。无需额外开关：私聊白名单内直接发送，群聊按现有 @／关键词规则触发。常见 QQ 原生表情以 `[QQ表情：微笑]` 等文字形式交给模型，未知编号标注名称未知，由模型结合上下文回复，不伪造名称。文本和表情的原始顺序会保留，按普通对话计费和保存上下文。图片表情包继续使用图片识别功能。

### 联网搜索

在 `.env` 设置 `WEB_SEARCH_ENABLED=true` 并重启，授权私聊发送 `/搜索 完整查询内容`、`/联网搜索 完整查询内容` 或“搜索 完整查询内容”“联网搜索 完整查询内容”。群聊支持 `@机器人 /搜索 明天北京天气`、`@机器人 搜索 明天北京天气`。请通过QQ实际@机器人。问题应完整独立，不能只写“帮我查这个”。

搜索使用现有 DeepSeek API 密钥和同一服务商的 Anthropic 兼容接口，只发送本条查询内容及固定检索说明，不发送已有聊天历史、自定义人设或本条图片。回答末尾附最多3个结构化搜索来源；搜索失败或没有可验证来源时明确提示，不伪装成已联网。

自动搜索开关 `WEB_SEARCH_AUTO_ENABLED=false` 默认关闭，关闭时只有上述搜索命令会联网。自行改为 `true` 并重启后，私聊及群内符合触发规则的文本问题包含“天气、气温、新闻、热搜、实时、最新”，或包含“今天／现在／最近”等时间词与“价格／版本／动态／赛程／比分”等信息词时，会自动联网；例如 `@机器人 明天北京天气怎么样`。这是本地关键词判断，不保证识别所有需要时效的问题，未匹配时可手动搜索。自动搜索也需要总开关 `WEB_SEARCH_ENABLED=true`，总开关关闭时普通问题继续走正常模型对话。

自动搜索不会让机器人主动回复全部群消息：仍需群白名单和现有@／关键词规则。只搜索当前文本问题，不补发之前的聊天记录或群成员身份；含图片的问题继续识图，不自动搜索。搜索结果是独立事实回答，未搜索或搜索失败时不会声称已经联网。自动搜索与手动搜索共用每日次数与金额预算；问题超过500字请缩短后重试。

搜索按独立事实查询作答，不套用毒舌人设；发送成功后，当前查询与带来源的答复作为正常对话保存，供后续普通聊天使用。违禁词仍在发送请求前拦截，命中消息及固定回复不记入上下文。网页内容不能触发群管理接口。

所有搜索与普通聊天共用每日人民币预算。默认每次最多1次服务端搜索，`WEB_SEARCH_DAILY_LIMIT=50` 控制全体用户的每日总次数，重启不重置；失败请求也占次数。搜索内容及服务端总结会增加模型 token，调用前额外预留 `WEB_SEARCH_INPUT_RESERVE_TOKENS=64000` 个输入 token 的费用；实际 usage 按缓存未命中高峰价保守结算。预留是本地估计，不是服务端检索 token 硬上限；若 usage 超过预留会锁定当日后续调用，超时或 usage 缺失时保留额度，不自动重试。

`node --env-file=.env scripts/search-check.js` 使用一条公开固定查询验证真实搜索，产生小额费用并使用一次当日搜索次数。普通模型接口地址若更换为其他服务，该服务还须支持 `/anthropic/v1/messages` 原生 `web_search_20250305`，否则搜索会失败，普通聊天不受影响。

接口依据：[DeepSeek 官方联网搜索说明](https://api-docs.deepseek.com/quick_start/agent_integrations/claude_code/)；结构化结果说明参考[官方搜索适配器文档](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/web/web-search-deepseek/README.md)。

### 私聊群管理（禁言／解除禁言）

在 `.env` 设置 `GROUP_MANAGEMENT_ENABLED=true` 并重启，设为 `false` 即关闭。默认范例关闭此功能。控制者是 `PRIVATE_USER_QQ`；该字段为空时，取 `PRIVATE_USER_QQS` 列表第一人。其他私聊白名单用户和 `ADMIN_QQ` 不会自动取得此权限。

仅支持控制者发送明确的私聊命令：

```text
/群管理帮助
/禁言 群号 成员QQ 分钟
/解除禁言 群号 成员QQ
```

例如 `/禁言 10000003 10000004 10` 是禁言10分钟，解除禁言用同样的群号与成员QQ。时间为1～43200整数分钟。目标群必须在 `GROUP_QQS`／`GROUP_QQ` 白名单内，机器人必须是群主或管理员，机器人是管理员时目标必须是该群普通成员；机器人是群主时也可对该群管理员操作，群主和机器人自身不能作为目标。执行前实时查询机器人和目标成员信息，验证身份与角色；权限变化时以 QQ 接口最终结果为准。

命令执行不调用 AI、不计模型费用、不写对话上下文；模型输出不能触发群管理接口。它独立于 `/停止`（暂停模型回复），仍受私聊限流和事件去重约束。连接中断或结果未知不自动重试，收到结果未知提示时在 QQ 核实。控制者若不在普通私聊白名单内，仅能发送这些群管理命令，不会因此获得聊天权限。

本期提供单人禁言和解除禁言，不开放任意 OneBot API、踢人、解散群或授予管理员权限。接口依据：[OneBot v11 公共 API](https://github.com/botuniverse/onebot-11/blob/master/api/public.md)。

`node --env-file=.env scripts/group-permissions.js` 只读检查当前开关、控制者与机器人在各群的角色，不执行禁言，也不调用模型。

### 违禁词拦截与关键词触发模型

编辑 `.env`，用英文逗号分隔多个词。例如（仅为格式示例，请替换为自己的词）：

```dotenv
BLOCK_TERMS=违禁词一,违禁词二
TRIGGER_TERMS=关键词一,关键词二
GROUP_KEYWORD_WITHOUT_AT=false
```

消息包含任意违禁词，就直接回复“我是什么都不会告诉你的”，不调用模型、不花模型额度、不写入对话上下文。消息包含触发关键词时，则像 @ 机器人一样正常调用模型：传入整条消息、已有上下文与人设，生成回复，成功发送后保存正常对话，并计入每日预算；例如“你好呀，帮我解释这段话”会交给模型完整回答，不再固定回“你好”。违禁词优先于关键词；同时命中多个关键词只发起一次模型请求。采用子串匹配，英文字母忽略大小写，不使用正则表达式。留空表示关闭对应列表。`BLOCK_TERMS` 同时检查模型输出；模型输出被拦截时，已经发生的 API 费用仍会记账。`TRIGGER_TERMS` 只检查用户输入，不检查模型输出。

默认仅处理白名单私聊和白名单群的 @ 消息；设置 `GROUP_KEYWORD_WITHOUT_AT=true` 后，群里未 @ 的关键词消息也可触发模型，未 @ 的违禁词消息会固定拦截，其余普通群消息继续忽略。其他群和未授权私聊不触发。白名单私聊本来就会对普通文本调用模型，不需要包含关键词。两类规则仍遵守限流、去重、全局停用及群停用；管理和清空、状态命令优先处理。改完双击 `restart.cmd` 生效。

输入命中违禁词时，整条用户消息和本地固定回复都不会保存到 AI 对话上下文，也不会带入之后的模型请求；已有的正常聊天历史继续保留。这条规则对私聊与白名单群聊都适用。关键词触发属于正常模型对话，成功回复后会记录上下文。

| 字段 | 用途 |
| --- | --- |
| `MODEL_NAME` | 当前默认 deepseek-flash；切换模型时同时核验并更新价格 |
| `DAILY_BUDGET_CNY` | 全部私聊和群聊合计的每日人民币预算，当前为 1 |
| `MAX_OUTPUT_TOKENS` | 单次回答输出 token 上限，当前为 1024 |
| `CONTEXT_INPUT_TOKENS` | 输入容量上限，当前为 16000，使用保守估算 |
| `GROUP_CLEAR_HOURS` | 群上下文自动清理间隔，当前为 72 |
| `MODEL_TIMEOUT_MS` | 模型请求超时毫秒，当前为 60000 |
| `BLOCK_TERMS` | 输入／输出简单拦截词，英文逗号分隔 |
| `TRIGGER_TERMS` | 输入触发关键词，英文逗号分隔，触发正常大模型回复 |
| `GROUP_KEYWORD_WITHOUT_AT` | true 允许目标群无需 @ 触发规则，默认 false |

群清理已保存的下一次截止时间不会因修改间隔立即重新计时；下一次到期后按新间隔推进。私聊不参与定时清理。

`DEEPSEEK_API_KEY`、`ONEBOT_ACCESS_TOKEN` 是密钥，不要发给别人或写入可提交的范例。修改 OneBot Token／端口后，还需要运行 `node --env-file=.env scripts/configure-napcat.js` 同步 NapCat 配置并重启 NapCat；单纯更换人设、名单和预算只需重启 AutoChat。

## 启动、停止、重启

```powershell
npm run bot:start
npm run bot:stop
npm run bot:restart
```

这些命令管理当前的后台 AutoChat 服务，不关闭 NapCat，也不关闭其他 QQ／Node 进程。重启会先检查配置，检查失败则保留现有运行服务。后台停止使用进程停止方式，建议等机器人当前回复完成后再执行；在途请求的未知费用预留会保留，不会因重启释放预算。

若要前台看日志，先 `npm run bot:stop`，再 `npm start`；按 Ctrl+C 停止前台服务。前台实例不由后台 PID 文件管理，不要同时启动前后台两个实例。

## 检查与排错

```powershell
npm run check
npm run check:connection
npm run status
```

分别是配置校验、真实 NapCat 连接检查、持久化事件和当日账本统计。`npm run check:model` 会真实调用模型并产生小额费用，其余上述诊断不调用模型。

AutoChat 日志在 `logs/`，启动输出／错误在 `runtime/autochat-output.log` 和 `runtime/autochat-error.log`。如重启后无回复，先检查连接，再检查白名单、群号、是否正确 @，以及管理员是否关闭了回复。

管理员可在 QQ 私聊中发送 `/状态`、`/停止`、`/启动`、`/群关闭`、`/群开启`。QQ 命令 `/停止` 只暂停模型回复，进程继续运行；它与 `npm run bot:stop` 的停止进程不同。
## 图片识别

在 `.env` 设置 `VISION_ENABLED=true`，双击 `restart.cmd` 重启即可。默认范例关闭，本机可按需开启。继续使用支持图像输入的 `deepseek-flash`，无需额外密钥。

白名单私聊直接发送图片，或发送图片并附上“这是什么”“提取图片中的文字”等问题；白名单群中需 @机器人并附图（已有关键词触发规则仍适用）。没有问题时会描述图片并识别文字。每条最多3张，每张最大5MB，支持 JPEG、PNG、GIF、WebP；暂不处理合并转发中的图片、视频或任意外部图片链接。图片下载失败会提示重新发送，不调用模型。

`VISION_DETAIL=original` 默认保留细节，适合截图和小字；可改为 `low` 减少细节和费用。每张额外预留2048输入 token（官方当前上限1024，加保守余量），之后按实际 usage 结算，共用每日1元预算，不自动重试。运行 `node --env-file-if-exists=.env scripts/vision-check.js` 可以用程序生成的测试图验证真实接口，会产生少量费用并记入账本。

图片从QQ CDN下载后，以内存中的图片数据发送给 `.env` 配置的模型服务商；本程序不保存原图、下载链接或 base64 到日志／SQLite，上下文只保留问题和模型文字回答。QQ／NapCat 自身可能保留图片缓存，不由本功能清理。后续追问基于已识别的文字回答，需要进一步查看细节请重新发图。识图与 `/搜索` 请分开发送。

文本违禁词在下载和模型调用前拦截，拦截消息不进入上下文。图片内部文字需要模型识别后才可检查回复，不能保证图片中出现的违禁词在送入模型前被拦截；模型回复命中违禁词时仍返回固定句且不写入上下文。
