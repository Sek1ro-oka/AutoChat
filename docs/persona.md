# 人设与两层提示词

AutoChat 的系统提示词分两层管理，对应 [V2 开发路线图](roadmap.md) 的 Phase 2。

## 优先级

```
SYSTEM_PROMPT（.env，若已填写 → 独占，忽略下面两层）
        ↓
personas/behavior.md          行为层：作为群友的行为协议   —— 需重启
        ↓
启用的人格卡 characters/*.md   人格层：语气、口癖、禁区     —— 即时生效
        ↓
src/persona.js 的内置默认人设
```

- **默认状态＝今天的行为。** 没写 `behavior.md`、没启用任何人格卡、`.env` 也没设 `SYSTEM_PROMPT` 时，合成结果就是内置默认人设 `src/persona.js`，与升级前逐字节一致。
- **`SYSTEM_PROMPT` 仍是最高优先级覆盖。** 它一旦非空，就完全接管系统提示词，人格卡与行为层都不参与——这是给"只想用一长串自定义提示词"的用户保留的旧路径。
- 私聊与群聊共用同一份提示词；开启拟人化群友后，群里的主动发言也用**同一份**合成结果（见 [拟人化群友](simulation.md)），区别只在调用时追加了一段"这一次是在群里自主发言"的简短说明。
- **人格卡可按群覆盖**：控制台「群设置」页能给单个群指定一张人格卡，覆盖全局选择。未指定的群继承全局；私聊始终用全局。机制见 [按群特异化](groups.md)。

## 两层文件

| 层 | 位置 | 内容 | 生效时机 |
| --- | --- | --- | --- |
| 行为层 | `personas/behavior.md` | 「作为群友的行为协议」：何时可以开口、怎么分句、什么时候闭嘴 | 保存后**需重启**（协议改动影响面最大，重启更安全） |
| 人格层 | `personas/characters/<名称>.md` | 角色卡：语气、口癖、偏好、禁区 | **下一次模型调用即生效**，无需重启 |

人格层的热更新靠**每次对话前做一次 mtime 校验**（缓存以 `(mtime, size)` 为键），而不是 `fs.watch`：后者在 Windows 上会漏事件，且给进程增加一个需要在关闭时清理的句柄。

控制台「人格」页会在保存时展示「待重启生效」标记，所以不会出现"改了没动静"的困惑。

## 管理方式

推荐用控制台的**人格**页（见 [控制台说明](console.md)）：

- 人格卡：列表、新建、编辑、改名称另存为、删除、启用／停用、恢复内置默认；
- 行为层：在线编辑、保存；
- 展示当前生效来源与合成后的系统提示词预览（前 800 字）。

也可以直接改文件。人格卡改完下一条消息就生效；行为层需要重启。

按群覆盖的优先级在 `active(group)` 里：**群覆盖 > 全局启用卡 > `.env` 默认 > 内置默认**。`SYSTEM_PROMPT` 一旦设置仍独占一切（按群覆盖也不参与）。

## 磁盘与容错

- 保存人格卡走**原子写入**（同目录临时文件 + 改名），断电或崩溃不会留下半截文件。
- 文件是**唯一事实来源**。SQLite 的 `personas` 表只镜像**最近一次保存的内容**，仅在某张卡的文件**无法读取**（I/O 错误或超过 64 KB）时兜底。
- 文件被**删除或清空**视为"没有这张卡"，**不会**从镜像复活——所以控制台里的删除是真的删除。
- 删除正在启用的人格卡会自动清空选择，回退到内置默认，不会留下悬空引用。

## 约束

| 项 | 限制 |
| --- | --- |
| 名称 | 1~40 字；可用中英文、数字、空格、点、短横线、间隔号；不能以点或空格开头/结尾；禁止路径分隔符与 Windows 保留名（`con`、`nul`、`com1` 等） |
| 单卡大小 | 64 KB |
| 卡片数量 | 50 张 |
| 路径 | 名称先过白名单校验，再校验解析后的绝对路径仍位于 `characters/` 内，双重防穿越 |

## 内置默认人设

当前内置默认：熟悉网络梗、更加毒辣，带"雌小鬼"式挑衅与嘴硬反差的成年女性 AI 角色。私聊和群 @ 共用。

风格：嚣张、自信、爱抓槽点、反问补刀；日常一到三句短句，遇到嘴硬、炫耀或游戏翻车时适量用"杂鱼杂鱼～""欸，这就急啦？"等口头禅，轮换表达，不每条重复。合理指出错误时认错改正，认真求助时回答，遇到难过或危机收起嘲讽。

追加风格：普通闲聊、显而易见的问题、嘴硬或讨夸时，可以更频繁地只用梗、反问或尖锐吐槽回应，不正面解答，也不在吐槽后自动补一大段答案。用户明确要求认真回答或停止玩梗时恢复正常作答。是否吐槽由语境决定，没有固定随机概率。

语气示例（用于说明风格，不是每次照抄的固定回复）：

- 用户："我又熬夜到三点了。" → "好好好，白天困成加载界面，晚上精神得像刚开服。先去睡，明天再研究怎么当夜行动物。"
- 用户："这题我看不懂。" → "题目还没动手，你先把自己劝退了是吧。把题发来，我帮你拆开看。"
- 用户："你是不是很关心我？" → "少给自己加戏。我只是看不下去你把简单模式打成地狱难度。"
- 用户："我是不是天才？" → "典，先把自信点满，其他属性以后再说。"
- 用户："我游戏十连跪。" → "欸，连跪都能稳定发挥，你也算反向天才了～"
- 用户："你这句说错了。" → "这次算你赢。刚才那句确实不对，应该是……"

`personas/characters/默认角色.md` 是这份人设的**可编辑副本**，默认未启用；在控制台点「启用」后它才会取代内置默认。这样"改人设"从改源码变成改数据。

2026-10-03 参考[萌娘百科的角色属性说明](https://moegirl.uk/%E9%9B%8C%E5%B0%8F%E9%AC%BC)，提取高傲、嘲弄和傲娇反差作为语言创作参考。本项目采用成年角色的非色情互动，不复制网页原文。

## 其他既有约定（未改变）

- 更新人设不清空现有会话、不改变白名单或预算。下一次模型调用使用新的系统提示词。
- 违禁词命中时固定拦截，不进入人设生成；关键词命中时使用完整消息和当前人设正常调用大模型。
- 自动搜索默认关闭，不宣称知晓未检索的实时热搜；显式 `/搜索` 命令独立检索，开启 `WEB_SEARCH_AUTO_ENABLED` 后天气、新闻、最新动态等文本问题也可自动检索。搜索阶段只发送当前问题，最终回答阶段结合当前人设、对话上下文和检索资料，用自然纯文本回复。
