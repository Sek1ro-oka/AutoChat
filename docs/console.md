# Web 控制台

本机控制台，用于观察 AutoChat 的运行状态、会话、花费、日志与生效配置，并管理人格、仿真参数与黑话词库。对应 [V2 开发路线图](roadmap.md) 的 Phase 1（控制台）、Phase 5（花费看板）、Phase 2（人格）、Phase 3（仿真）与 Phase 4（黑话）。计费口径见 [令牌与花费看板](cost.md)，人格分层见 [人设与两层提示词](persona.md)，群友仿真见 [拟人化群友](simulation.md)，黑话词库见 [群聊黑话词库](slang.md)，完整威胁模型与残余风险见 [安全与隐私基线](security.md)。

## 开启与访问

在 `.env` 中设置：

```ini
CONSOLE_ENABLED=true
CONSOLE_PORT=3200
# 可选；留空则首次启动自动生成
CONSOLE_TOKEN=
```

重启后，启动日志会打印一行带令牌的地址，例如：

```
AutoChat 控制台：http://127.0.0.1:3200/?token=xxxxxxxx
```

用浏览器打开该地址即可。页面会把令牌记到浏览器本地存储，并立刻从地址栏移除 `?token=`，避免令牌留在历史记录里。

若未指定 `CONSOLE_TOKEN`，令牌会在首次启动时自动生成并写入 `runtime/console-token.txt`。该文件的访问控制是**每次启动都会执行的显式收紧**（只留当前账号、SYSTEM、Administrators），不只是创建时——Windows 会忽略 Node 的 `mode: 0o600`，所以"看起来设了权限"并不等于设了权限，且升级时要能修好旧文件。想更换令牌，删掉该文件并重启，或在 `.env` 显式指定。机制与实测细节见 [安全与隐私基线](security.md)。

## 页面

| 页面 | 内容 |
| --- | --- |
| 运行总览 | 今日已用／预留／剩余预算与进度条、队列深度、连接状态、运行时长、各开关状态、参与者异常计数、各群下次清理时间 |
| 会话 | 会话键、范围（private / group:群号）、条数、最后更新时间。**不展示聊天内容** |
| 花费与令牌 | 区间花费（高峰/空闲拆分）、累计 token（未命中/命中/输出）、缓存命中率、平均每轮；24h／3d 按小时、7d／30d 按天的峰谷着色走势图；按会话表（可点击下钻逐轮明细）；最近 20 次采样流水；以及预算账本本身的按账期预留与结算。口径见 [令牌与花费看板](cost.md) |
| 人格 | 两层提示词管理：生效来源、行为层编辑（保存后**需重启**）、人格卡列表（新建／编辑／另存为／删除／启用／恢复内置默认）、合成提示词预览。详见 [人设与两层提示词](persona.md) |
| 仿真 | 拟人化群友：总开关、相关度阈值、冷却、每群日上限（保存即生效）；每群状态（观望／试探／活跃／退场）、能量、2 分钟内消息数、今日发言与上限、距上次发言、最近一次判定的原因与分数、单群静音。**不展示任何聊天正文**。详见 [拟人化群友](simulation.md) |
| 黑话 | 群聊黑话词库：功能开关、按状态筛选的词条列表、逐条确认／拒绝／详情改义／联网查义／删除、按群触发候选抽取、导出／恢复备份，以及**当前注入进提示词的原文**。记录中的原句只在点开单条详情时显示。详见 [群聊黑话词库](slang.md) |
| 日志 | 最近事件名称与时间（`logs/*.jsonl` 的尾部）。日志只含固定事件名，不含聊天正文与密钥 |
| 配置 | 生效配置与模型配置；所有凭据字段打码 |

除「人格」「仿真」「黑话」页外，页面每 3 秒轮询一次当前页，切到后台标签页时暂停。**这三页不轮询**——它们保存着未提交的编辑内容（人设文本、阈值数字、词条含义），自动重绘会打断输入；只在切换页面、点击刷新或执行动作后重绘。左下角主题按钮可在浅色／深色间切换，未选择时跟随系统。

页面外壳（`index.html`）只含样式与导航；脚本拆成 `pages.js`（各页渲染函数）与 `app.js`（令牌、主题、格式化、请求与调度），按此顺序加载。三者都是 `public/` 下的静态资源，白名单路由，不走令牌鉴权——它们是代码而不是数据，浏览器自己的 `<script>` 请求也无法携带请求头。

## API

所有 `/api/*` 都需要令牌。读接口两种方式皆可：

- 请求头 `x-console-token: <token>`
- 查询参数 `?token=<token>`

**写接口（POST）只接受请求头里的令牌**，且当请求带 `Origin` 时必须是回环地址。这是刻意的：URL 里的令牌可被第三方页面复用，而跨站页面既无法给简单请求加自定义头，也无法通过我们从不回应的 CORS 预检，因此写接口不可被 CSRF 触发。

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/summary` | 运行总览数据（连接、开关、预算、队列、参与者、群清理时间） |
| GET | `/api/sessions?limit=200` | 会话列表（不含历史正文） |
| GET | `/api/charges?days=30` | 按账期的花费汇总（预算账本：预留与结算） |
| GET | `/api/cost?range=24h\|3d\|7d\|30d` | 令牌与花费看板：指标、走势、按会话汇总、最近采样 |
| GET | `/api/cost/turns?session=<会话键>&limit=100` | 指定会话的逐轮明细 |
| GET | `/api/logs?limit=120` | 最近事件（固定事件名） |
| GET | `/api/config` | 生效配置（凭据打码） |
| GET | `/api/personas` | 两层提示词状态：生效来源、行为层、人格卡列表、合成提示词预览 |
| GET | `/api/personas/file?kind=card\|behavior&name=<卡名>` | 读取人格卡或行为层正文（供编辑器） |
| POST | `/api/personas/file` | 保存。`{kind:'behavior',content}` 保存行为层（需重启）；`{kind:'card',name,content}` 保存人格卡（即时生效）；改名即另存为 |
| POST | `/api/personas/delete` | `{name}` 删除人格卡 |
| POST | `/api/personas/active` | `{name}` 切换启用的人格卡；`name` 为空串表示恢复内置默认 |
| GET | `/api/social` | 仿真状态：开关、阈值/冷却/日上限、每群状态与能量、今日发言计数、最近一次判定原因（**不含消息正文**） |
| POST | `/api/social/config` | 调整仿真参数：`{enabled}`、`{threshold}`、`{cooldownSeconds}`、`{dailyLimit}`、`{group,muted}`；均为可选补丁，立即生效并写入本机设置 |
| GET | `/api/slang` | 黑话词库：开关、统计、容量、上次抽取、每群可抽取的群列表、**当前注入原文**、词条列表（**不含记录中的原句**） |
| GET | `/api/slang/entry?id=<id>` | 单条词条详情，含记录中的原句（显式点击才取） |
| GET | `/api/slang/export` | 导出整库备份（JSON） |
| POST | `/api/slang/config` | `{enabled}` 打开／关闭黑话功能 |
| POST | `/api/slang/extract` | `{group}` 抽取候选。**会调用一次模型并计入每日预算** |
| POST | `/api/slang/status` | `{id,status}`，`status` 为 `candidate`／`confirmed`／`rejected`；只有 `confirmed` 会进入提示词 |
| POST | `/api/slang/entry` | `{id,meaning?,usage?,example?,risk?}` 修改词条文本，不改变确认状态 |
| POST | `/api/slang/delete` | `{id}` 删除词条 |
| POST | `/api/slang/lookup` | `{id}` 联网查义。**会消耗一次搜索额度与模型预算**，结果仍需人工确认 |
| POST | `/api/slang/import` | `{text}` 恢复备份；按词条内容加法合并，保留本地的人工确认状态 |

未通过鉴权时返回 `401 {"error":"unauthorized"}`；写接口缺请求头令牌返回 `403 {"error":"header_token_required"}`，来源非回环返回 `403 {"error":"origin_rejected"}`；未知路径返回 `404`。写接口的校验失败使用明确状态码：名称非法 `400`、内容为空 `400`、内容超限 `413`、卡数达上限 `409`、卡不存在 `404`、仿真参数越界或未知群 `400`；黑话为参数非法 `400`、词条不存在 `404`、功能未开启／预算不足／搜索未启用 `409`、搜索次数用尽 `429`、模型失败或返回不可解析 `502`。

`/api/slang/import` 的请求体上限放宽到 2MB（其余写接口为 128KB），因为整库备份可能包含上限 2000 条词条。

## 安全边界

1. **只绑回环**：服务端硬编码绑定 `127.0.0.1`，不接受外部地址，因此局域网与公网无法访问。这与 OneBot 正向连接的设计一致——不需要暴露端口。
2. **令牌鉴权**：`/api/*` 全部需要令牌；比较使用定长常量时间比较，避免时序侧信道。
3. **凭据打码**：任何形如 `key`／`token`／`secret`／`password` 的字段在响应里都会被遮罩，从不返回明文。
4. **页面本身不含数据**：`/` 只返回静态外壳，任何真实数据都要过令牌。
5. **写入面极小且受额外约束**：观测页面全为只读；写操作只有「人格」页（保存行为层／人格卡、删除、启用）、「仿真」页（开关、阈值、冷却、日上限、单群静音）与「黑话」页（开关、抽取、确认／拒绝、改义、删除、联网查义、恢复备份），以及首次生成令牌文件。写接口额外要求**请求头令牌 + 回环 Origin**，不接受查询参数令牌（见上）。人格写入只落在 `personas/` 目录内的 `behavior.md` 与 `characters/*.md`——卡名经过字符集白名单与路径包含双重校验，不产生路径穿越；落盘走临时文件原子重命名，崩溃不会留下半截文件。仿真参数是一组**经过范围校验的数值与布尔量**，只写入 `settings` 表的固定键，不能指定任意键名。黑话只写 `slang` 表的固定列：状态限三个枚举值，文本经 `sanitiseText()` 压平并截断，`id` 必须已存在；恢复备份解析失败时**不改动词库**，而是把原文另存到 `runtime/slang-corrupt-<时间戳>.json`。
6. **不打印聊天内容**：控制台只读 `logs/`（固定事件名）与数据库的**结构信息**（条数、时间、状态），不读会话正文。人格页编辑的是**人设文本**，仿真页展示的是**判定原因与计数**，都与会话正文无关。黑话页的列表接口同样不返回记录中的原句，只有点开单条详情时才返回该条的依据（见 8）。
7. **花费看板不含正文**：Phase 5 的采样只存 token 计数、会话键与时间，不存提问或回答文本。
8. **群消息流水不对外开放**：Phase 3 的 `messages` 表（群聊正文）没有任何 API 读取入口，控制台也不会展示它。Phase 4 的黑话词条里会带一条**记录中的原句**作为判断依据，它是唯一从群消息正文派生出来的字段，因此列表接口不返回它，只在 `GET /api/slang/entry?id=<id>` 这一个人工点击下返回单条。
9. **不可被套壳**：所有响应带 `X-Frame-Options: DENY` 与 `Content-Security-Policy: frame-ancestors 'none'; base-uri 'none'; form-action 'none'`。写接口本身就接受同源请求，所以一个能把控制台套进不可见 iframe 的第三方页面会是通往人格／黑话编辑器的点击劫持路径。页面**零外部资源**，这条 CSP 不依赖任何 CDN，不会影响渲染。

> 令牌等同于控制台访问权，请像对待 `.env` 一样保管。`runtime/` 已被 Git 忽略。

## 排查

| 现象 | 处理 |
| --- | --- |
| 页面提示「缺少访问令牌」 | 用启动日志里带 `?token=` 的完整地址打开 |
| `401` | 令牌不匹配。检查 `runtime/console-token.txt`，或清掉浏览器本地存储后重开带令牌的地址 |
| 端口被占用 | 改 `CONSOLE_PORT` 后重启；启动失败只记录日志，不影响机器人本体 |
| 控制台没起来 | `CONSOLE_ENABLED` 是否为 `true`；看启动日志中是否有「控制台启动失败」 |
